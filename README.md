# EnglishFlow

Интерактивная веб-среда для изучения английского языка. Теория, практика и словарный запас в одном месте с акцентом на качественный UX/UI.

## Возможности

- **Грамматика** — структурированные темы с теорией (Present Simple, Past Simple, Future Simple, Present Continuous, Articles, Modal Verbs, Conditionals)
- **Практика** — случайные задания из всех тем: перевод предложений, тесты, заполнение пропусков
- **Слова** — интерактивные флешкарды с транскрипциями и примерами
- **Прогресс** — отслеживание изученных слов и выполненных заданий

## Технологии

- **Next.js 16** (App Router)
- **TypeScript**
- **Tailwind CSS v4**
- **shadcn/ui**
- **Prisma ORM** + SQLite
- **Framer Motion** — анимации

## Запуск

```bash
# Установка зависимостей
npm install

# Генерация Prisma Client и миграции
npx prisma migrate dev
npx prisma db seed

# Запуск в режиме разработки
npm run dev

# Сборка
npm run build
npm start
```

## Структура контента

База данных наполняется автоматически через `prisma/seed.ts`:
- 7 тем грамматики
- 30+ упражнений
- 113 слов с транскрипциями и примерами
